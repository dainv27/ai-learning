## Requirement

Viết một AWS Lambda function (Node.js 22, handler ES module) đứng sau API Gateway HTTP API, endpoint GET /provinces trả về JSON danh sách các tỉnh/thành phố trực thuộc trung ương của Việt Nam hiện hành, mỗi phần tử gồm code (mã hành chính) và name (tên tiếng Việt có dấu). Hỗ trợ query ?q= lọc theo tên không phân biệt hoa thường và dấu, trả 200 kèm header Content-Type application/json và Cache-Control, trả 405 cho method khác GET. Dữ liệu tĩnh nhúng trong code. Kèm unit test cho handler và template triển khai AWS SAM (template.yaml).

## Decision

Lambda module is a pure ES module adapter: handler.js parses API Gateway HTTP API v2 events, calls a pure domain function findProvinces(q) over an embedded PROVINCES array, and returns statusCode/headers/body; q is matched by normalized substring (NFD strip combining marks, đ->d, lowercase). template.yaml defines an AWS::Serverless::HttpApi with OpenAPI x-amazon-apigateway-any-method on /provinces so non-GET methods reach the handler and return 405; GET returns 200 with Content-Type: application/json and Cache-Control: public, max-age=3600. Unit tests use node:test and call the handler directly without AWS.

## Constraints

- Must be Node.js 22 ES module: package.json must set "type":"module" and handler must be a named export, not CommonJS.
- SAM template must not define only a GET route; it must expose ANY /provinces (or equivalent $default route) to the Lambda, otherwise API Gateway will not deliver non-GET methods and the required 405 cannot be returned.
- Handler must expect and return API Gateway HTTP API v2 payload format: event.requestContext.http.method and response {statusCode, headers, body} where body is a JSON string.
- GET 200 response headers must contain exactly Content-Type: application/json and Cache-Control with public,max-age=3600; missing or misspelled header keys fail the contract.
- The q filter must operate on name only, after normalizing both the stored name and q with the same Vietnamese diacritics-insensitive normalization; missing q returns the full list, no match returns [].
- Embedded PROVINCES data must be the current official 63-province/city list, with string codes preserving leading zeros and names containing full Vietnamese diacritics; no runtime fetch, database, or network access is allowed.
- Unit tests must run locally without AWS credentials or deployed resources; they must cover 200 with/without q, diacritics-insensitive matching, and 405 for non-GET.
