## Requirement

Viết một AWS Lambda function (Node.js 22, handler ES module) đứng sau API Gateway HTTP API, endpoint GET /provinces trả về JSON danh sách các tỉnh/thành phố trực thuộc trung ương của Việt Nam hiện hành, mỗi phần tử gồm code (mã hành chính) và name (tên tiếng Việt có dấu). Hỗ trợ query ?q= lọc theo tên không phân biệt hoa thường và dấu, trả 200 kèm header Content-Type application/json và Cache-Control, trả 405 cho method khác GET. Dữ liệu tĩnh nhúng trong code. Kèm unit test cho handler và template triển khai AWS SAM (template.yaml).

## Decision

Implement single AWS Lambda handler 'provincesHandler' as ES module in src/handler.mjs, with static province data in src/data/provinces.mjs, normalization function for Vietnamese diacritics in src/utils/normalize.mjs; export handler function that validates HTTP method (GET required, else 405), parses q query param, filters provinces by normalized name, returns 200 JSON with Content-Type and Cache-Control headers; SAM template.yaml defines Lambda function with runtime nodejs22.x and API Gateway HTTP API integration; unit tests in test/handler.test.mjs using built-in node:test.

## Constraints

- Only GET allowed, any other method must return HTTP 405 with Allow: GET header; else QA fails.
- Response must always have Content-Type: application/json and Cache-Control header; missing header fails contract test.
- Query ?q= filtering must ignore case and Vietnamese diacritics (e.g., 'ha noi', 'HÀ NỘI', 'hà nội' all match 'Hà Nội'); incomplete normalization fails acceptance test.
- Static province data must include all 63 current provinces/cities with correct administrative codes and diacritic names; any missing or wrong entry fails data integrity test.
- Handler must be ES module (Node.js 22), not CommonJS; deployment via SAM template using provided template.yaml must succeed, else infra review fails.
- Unit tests must run with 'npm test' using Node's built-in test runner and cover: 200 with full list, 200 with q filter, 405 on POST, invalid q returns empty list; missing any test case fails QA.
- No external dependencies or network calls; data embedded in code, no database access, else violates 'static data' requirement.
- Response body must be JSON array, each element exactly {code, name}; extra fields or different shape fails contract test.
