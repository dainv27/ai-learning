- Requirement: Create a new AWS Lambda function (Node.js 22, behind API Gateway HTTP API) with GET /time returning JSON {"now": <current UTC time as ISO 8601 string>}. Optional query parameter tz is not supported: any other method returns 405. No UI.

## Architect
- Decision: Build a zero-dependency Node.js 22 ES-module Lambda in lambda/, deployed with AWS SAM behind an API Gateway HTTP API (payload v2). The function is `TimeFunction`. Its HttpApi event is declared as `Method: ANY, Path: /time`, not `GET /time`. HTTP API answers an unmatched method with its own 404 and never invokes the function, so the 405 and Allow header could only come from the function if all methods reach it. `src/handler.js` stays thin. It reads `requestContext.http.method` and `rawPath`, and returns { statusCode, headers, body } with a JSON string body. A non-GET method returns 405 with `Allow: GET` and the body `{error:{code:'METHOD_NOT_ALLOWED',message}}`. HEAD and OPTIONS are also 405, because the requirement says any other method. GET /time returns 200 with `{"now": <ISO 8601 UTC string>}`, produced by a pure function `getNow(clock)` in `src/time.js`. It uses `new Date().toISOString()`, which always ends in `Z`, and the clock is injectable so tests are deterministic. Unmatched paths are 404 from API Gateway, with a defensive 404 in the handler. The `tz` parameter is deliberately ignored: it is never read, never rejected, and the response is always UTC. A request with `?tz=Asia/Ho_Chi_Minh` returns 200 with the UTC time, and a test must pin this behaviour. Every response, including 405 and 404, sets `Content-Type: application/json; charset=utf-8`. Every response also sets `Cache-Control: no-store`, so the time is never cached. Any unexpected exception returns 500 with a generic body and no internals. Tests use `node:test` against the exported handler with realistic v2 events. They cover 200 (shape, ISO regex, fixed clock), 200 with tz ignored, 405 for POST, PUT, DELETE, PATCH, HEAD and OPTIONS with the Allow header, and 404 for a wrong path.
- Components: lambda/template.yaml (SAM: AWS::Serverless::Function TimeFunction, runtime nodejs22.x, HttpApi event ANY /time, Timeout 3, MemorySize 128, Output with the HttpApi endpoint URL), lambda/src/handler.js (exported `handler`; method and path routing, response building, 405 and 404 and 500 handling), lambda/src/time.js (pure `getNow(clock = () => new Date())` returning { now }), lambda/package.json (`"type": "module"`, `"test": "node --test"`, no dependencies), lambda/test/handler.test.js (node:test, handler-level tests for each status code and the tz-ignored case), lambda/test/time.test.js (node:test, unit tests for `getNow` with a fixed clock)
