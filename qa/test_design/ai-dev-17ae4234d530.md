# Test Design — Create a new AWS Lambda function (Node.js 22, behind API Gateway HTTP API) with GET /time returning JSON {"now": <current UTC time as ISO 8601 string>}. Optional query parameter tz is not supported: any other method returns 405. No UI.

- Workflow: `ai-dev-17ae4234d530`
- Repository (logical): `time-api`
- Module: `lambda`

## Requirement under test

Create a new AWS Lambda function (Node.js 22, behind API Gateway HTTP API) with GET /time returning JSON {"now": <current UTC time as ISO 8601 string>}. Optional query parameter tz is not supported: any other method returns 405. No UI.

## Objective

Verify that GET /time returns 200 with {"now": <UTC ISO 8601>}, that every other method returns 405 with Allow: GET, that tz is ignored, and that the architect's constraints hold (ANY /time route, headers on every response, generic 500, no dependencies, ES modules).

## Approach

Tests are designed from the requirement and the architect constraints. Unit tests cover getNow. Integration tests call the exported handler (createHandler with a fixed clock, and the default handler) with realistic HTTP API v2 events. Static checks read template.yaml and package.json to pin the routing and module constraints. Header names are looked up case-insensitively, because the requirement does not fix their casing.

### TC-001 — getNow returns the injected clock value as ISO 8601 UTC

1. Call getNow with a clock returning 2024-05-01T12:34:56.789Z

**Expected:** Result deep-equals {now:'2024-05-01T12:34:56.789Z'}

### TC-002 — getNow reads the clock on every call

1. Call getNow twice with a clock that advances

**Expected:** The two results differ and the clock was called twice

### TC-003 — getNow default clock returns the real current time

1. Record Date.now before and after
2. Call getNow()

**Expected:** now is ISO UTC and lies within the window
